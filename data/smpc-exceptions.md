Last reviewed: 2026-09-22

- Hydroxychloroquine — Plaquenil: direct current Irish SmPC record still to be confirmed.

- Ciclosporin — Neoral: medicines.ie lists Irish products but no SPC document is published there; obtain manufacturer/HPRA source or use labelled fallback.
- Sarilumab — Kevzara: direct Irish SmPC source still to be confirmed.
- Anakinra — Kineret: direct Irish SmPC source still to be confirmed.
- Bimekizumab — Bimzelx: direct Irish SmPC source still to be confirmed.
- Ustekinumab — representative current brand: direct Irish/EMA source still to be selected.
- Guselkumab — Tremfya: direct Irish SmPC source still to be confirmed.
